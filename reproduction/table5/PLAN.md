# TimeFT v2 Table 5 核心对照计划

## 对照与执行顺序

| 数据集 | 变量 | 频率 | v2 PatchTST MSE / MAE | v2 +TimeFT MSE / MAE | 论文下降 MSE / MAE |
|---|---:|---|---|---|---|
| ETTh1 | 7 | 1 小时 | 0.403 / 0.423 | 0.376 / 0.392 | 6.7% / 7.3% |
| ETTm1 | 7 | 15 分钟 | 0.321 / 0.361 | 0.290 / 0.339 | 9.7% / 6.1% |
| Weather | 21 | 10 分钟 | 0.155 / 0.204 | 0.147 / 0.194 | 5.2% / 4.9% |

1. 用真实 ETTh1 窗口跑两个小批量试运行，核对参数注册、梯度、Adam 更新、checkpoint 重载、窗口对齐、度量和数据落盘。
2. 用单张 GPU 和独立进程依次跑 ETTh1 PatchTST、ETTh1 +TimeFT。用两次完整运行核对结果和实际时间，按窗口数与变量数估计其余成本。
3. 按同一协议依次跑 ETTm1 和 Weather 各一对。每个配置使用固定种子 2021。测试集只在选好 checkpoint 后推理一次，各运行互不读取对照组结果来选模型。
4. 同步两组训练日志、参数、最佳 checkpoint、预测与共享测试窗，使用现有输出完成频域和信息保留分析，不重复训练。

## 参数与证据等级

| 项目 | 固定配置与依据 |
|---|---|
| 预测设置 | L=320、H=96、多变量全部通道。论文 §4.4 和 Table 5 |
| 数据 | 仓库原生 ETT 固定切分、Weather 70/10/20 切分。标准化只拟合训练段，测试损失在标准化尺度汇报 |
| 主干 | TSLib 风格的 PatchTST，通道独立、实例归一化、同一 Transformer 编码器和线性预测头。沿用本仓库相同实现，两边共享位置编码策略 |
| 模型参数 | 编码器 2 层、4 heads、d_model=512、d_ff=2048、dropout=0.1、GELU、patch 长度/stride=20/20。取公开 TimeFT ETTm1 320→96 脚本及默认值，固定给六次运行 |
| 训练 | Adam、MSE、batch=32、LR=5e-5、type1 学习率、最多 70 epoch、patience=5，按验证 MSE 选模型。沿用公开脚本及默认值 |
| 环境 | 远端镜像 Python 3.12、PyTorch 2.8 CUDA 12.8，数据和训练依赖单独安装。单 GPU，关闭 AMP，允许 TF32 矩阵乘法。记录实测环境 |
| 论文未公开的选择 | §D.8 说明作者分别调参，官方仓库未提供 Table 5 六组原始命令。这里使用一套可追溯的配对配置，无额外调参，比较同配置下效果及论文差距 |

`head.linear` 在创建 optimizer 前已注册。TimeFT 保留公开 RFFT、按频带移位、IRFFT 和相位布局，移除前向中写 `data.npy` 的调试副作用。配对模型统一位置编码，公开 TimeFT 实现将其注释。PatchTST 使用仓库现有的 TSLib patch embedding。实际 token 数和投影宽度分别记录，预测头尺寸随 token 数变化。公开 `FreqTokenizer` 和 `FreqEmbed` 保留供核对。确认包含此头的梯度、权重更新和严格 checkpoint 重载后才允许正式运行。

## 评价与成果

| 维度 | 度量 | 支持的判断 |
|---|---|---|
| Table 5 复现 | 标准化测试 MSE、MAE、相对下降和各自与论文差值 | 同一随机种子、同一数据设置下的收益方向和幅度 |
| 预测频域 | 按预测向量 RFFT 将平方误差分为 DC、低、中、高频，报告 Parseval 可加能量和分频相对变化。另评估以真值主频选出的幅值偏差与相位对齐 | 误差改善集中在哪段频谱。预测窗仅 96 步，频率分辨率由数据频率和窗口长度限制 |
| 输入保留 | 同一真实输入的完整 patch 覆盖重建与 TimeFT 逆变换误差、频带边界损失、单 token 频谱的解释性分析 | 局部 patch 的频谱泄漏与全体 patch 的信息可恢复性是不同性质。原始 token 分析不代表投影后的可逆性 |
| 计算 | 记录参数、token 数、每 epoch 训练和验证耗时、总训练时间、峰值显存与单次测试耗时 | 在当前实现和同张 GPU 上比较成本。论文复杂度分析的任务长度为 336，与本次实测设置不同 |

频率分析使用成对窗口、相同通道和相同切分，附每个数据集的周期换算。保留测试历史、未来真值、预测、窗口索引、归一化参数、配置、环境、日志、最佳 checkpoint 与可复算分析脚本。单种子与重叠滑窗仅支持描述性结论，频谱关联不能识别因果机制。
