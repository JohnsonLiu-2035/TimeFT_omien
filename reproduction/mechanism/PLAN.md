# TimeFT 机制验证

研究对象是既有 Table 5 的 PatchTST 与 PatchTST + TimeFT。固定输入 320 步、预测 96 步，优先复用种子 2021 的六个 checkpoint。主要结果是每个预测窗的均值 MSE。去均值后的波形 MSE 单独汇报，两项之和等于总 MSE。

| 假设 | 对照实验 | 判据 |
|---|---|---|
| H1 频带边界丢失的相位会形成严格不可区分的输入 | 改变边界频点的正弦分量符号，固定输入均值和方差。比较相邻带内频点，并在实测窗口上翻转相同分量 | 检查原始 token 和冻结预测的变化。构造未来均值不同的配对输入，推导不同预测长度下的最低均值 MSE |
| H2 频带边界信息解释了真实数据上的均值损失 | 在原始历史上训练共享口径的线性读出，比较完整输入、删除边界正弦分量、删除同等数量的相邻正弦分量。分别预测最近 4 小时对应的 24 步均值与未来 96 步均值相对整段历史的变化 | 判断边界删除相对两侧安慰剂的损失。真实任务的测量与合成反例分别解释 |
| H3 TimeFT 的表示较难读出近期变化，或原预测头未充分利用线索 | 冻结两个编码器。用同容量岭回归分别读嵌入层和编码器末层。另保持原预测曲线的去均值部分，给两组都用相同的均值校准。对照仅校准原均值、加入最近统计量、加入同维度早期统计量，也测原窗口均值与波动、盲频点与相邻频点的周期外推均值 | 看 TimeFT 的差距在嵌入层、编码器、预测头中的哪一步出现。比较近期信息的额外收益及其与分词方法的交互 |
| H4 Weather 初次测到的机制取决于测试时段或变量 | Weather 2020 测试段用于解释已发现现象。用相同测站的 2021 年组作独立时间检验，沿用 2020 训练段的标准化和已选择参数。ETTh1、ETTm1 作方向对照 | 结果按各数据集、变量和可观测近期偏移分组。另单列 2021 年 11–12 月，以核对相近季节。测试端仅用于评估，不选择参数。按自然时间的 7 天连续块做配对重采样，区间只反映同一组 checkpoint 的时间变异 |

H5 为并行数据审计中追加的探索性检验。将 Weather 训练 CSV 中的缺测占位数 `<= -9990` 从标准差估计中排除，以重新计算的尺度重评分旧的测试预测。该检验只判定评分权重能解释多少差距，训练受污染的效应需要另行对照。

## 固定分析口径

- 2020 训练窗用于拟合原始及冻结表示读出，验证窗用于选择正则。均值校准只用原验证期，按时间切为拟合段与选择段，中间留 415 个起点单位的间隔，两段不共享原始输入或目标时间戳。外部时期若无法核对测站、单位或共用通道，则不替代为来源不明的文件。
- 分组基于预测时可知的 `|mean(last 24) − mean(last 320)|`。各通道的高偏移阈值由原训练期第 75 百分位固定。分组结果解释为条件描述。所有模型用相同的起点与变量。
- 冻结读出仅比较同容量的线性解码能力。均值的一阶结构假设通过模型输出干预与实际窗口交叉验证。外部 2021 结果不会被用于再挑特征。线性读出和后处理会在现有 GPU 上完成，无需重新训练主干。
- 主要交付为逐组带证据的结论、可复算脚本、输入和 checkpoint 的哈希、原始预测与分段误差，并标明哪些观察足以成为后续论文假设。只有结果支持且需进一步验证时，再讨论多种子端到端与新预算。

TimeFT v2 已描述带起点相位损失。Dish-TS、SAN、FAN、TimeAPN 已研究未来统计量、时频变化或可逆归一化。可发展的方向是严格刻画特定分词器对有限预测任务的盲区，测量这种盲区在自然数据中是否重要，并与优化和分布变化区分。
